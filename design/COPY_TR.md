# Türkçe arayüz metinleri

| Anahtar | Metin |
|---|---|
| performance.off | Performans kapalı |
| performance.on | Performans açık |
| action.confirm | Evet |
| action.cancel | Hayır |
| action.apply_question | Bu değişiklikler uygulansın mı? |
| action.restore_question | Önceki ayarlara dönülsün mü? |
| test.builtin | Uygulama Testi |
| test.game | Oyunda Test |
| test.stop | Testi durdur |
| test.preparing | Test hazırlanıyor |
| test.insufficient | Güvenilir sonuç için veri yetersiz |
| diagnosis.none | Bu testte belirgin bir performans sorunu görülmedi |
| diagnosis.limited | Performansı sınırlayan etken tespit edildi |
| diagnosis.mixed | Birden fazla sınırlayıcı etken tespit edildi |
| metric.missing | Ölçülemedi |
| comparison.uncertain | İyileşme doğrulanamadı |
| comparison.no_cohort | Karşılaştırılabilir yeterli veri yok |
| support.unsupported | Bu cihazda desteklenmiyor |
| support.denied | Gerekli erişim sağlanamadı |
| state.no_changes | Uygulanabilir değişiklik bulunamadı |
| recovery.pending | Geri dönüş tamamlanamadı |
| reboot.pending | Yeniden başlatma gerekli |

Hata metni işlem adı ve yapılabilen sonraki adımı içersin. API enum, registry yolu, pipe veya developer task kimliği normal kullanıcı akışına taşınmasın. Ayrıntılı teknik log ayrı tanılama bölümünde ve hassas bilgiler ayıklanarak gösterilsin.
