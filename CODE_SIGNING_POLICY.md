# Kod imzalama politikası

> TASLAK: SignPath Foundation başvurusu kabul edilene kadar yayınlar imzasız alphadır. Kabul sonrası bu belge güncellenir.

- Resmi sürümler yalnız bu depodaki kaynaktan, otomatik derleme hattında üretilir ve imzalanır.
- Her imzalı sürüm, proje sahibi tarafından elle onaylanır (imzalama öncesi onay adımı).
- Proje sahibi (`ykp61`) tüm imza onaylarından sorumludur; hesaplarda çok adımlı doğrulama (MFA) kullanılır.
- Uygulama gizlilik: kullanıcı bilgisayarından veri toplamaz; ağ bağlantıları `site/gizlilik-kvkk.html` sayfasında listelidir.
- Marka: `TRADEMARK.md`.
- İmzalama sağlayıcısı atfı (kabul sonrası eklenecek): "Free code signing provided by SignPath.io, certificate by SignPath Foundation."
