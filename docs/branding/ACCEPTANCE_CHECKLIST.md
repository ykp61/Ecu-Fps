# Entegrasyon kabul listesi

Bu maddeler **uygulamaya entegrasyon** sırasında işaretlenir. Paket varlıklarının dosya kontrolleri ayrıca QA_REPORT.md içindedir. Burada kutuların boş olması uygulama testlerinin yapılmadığını gösterir.

- [ ] Mevcut depo talimatları ve kullanıcı değişiklikleri korunmuş.
- [ ] 02 / Boost kullanılıyor; yeni bir amblem üretilmemiş.
- [ ] Ürün adı Ecu Fps; görünür alanlarda eski geçici ad yok.
- [ ] Logo wordmark'ı fontla yeniden dizilmemiş, oranı korunmuş.
- [ ] Ana EXE ikon grubu doğru; pencere küçük/büyük ikonları ve Alt+Tab uyumlu.
- [ ] Explorer 16/32/48/256 görünümleri kontrol edilmiş; ikon önbelleğiyle gerçek kaynak karıştırılmamış.
- [ ] 100%, 125%, 150%, 200% ve mevcutsa 250%/300%/400% ölçekler denenmiş.
- [ ] 16/20/24 px kaynaklarda iki parça ve çentik hâlâ seçilebilir.
- [ ] Koyu ve açık Windows görev çubuğunda doğru tray sürümü kullanılıyor.
- [ ] Yüksek kontrastta görünürlük korunuyor; özel renk paleti için sistem renkleri değerlendiriliyor.
- [ ] İki monitör / DPI geçişinde yanlış boyut veya bulanık kaynak takılı kalmıyor.
- [ ] Explorer yeniden başladıktan sonra tray geri geliyor ve çift ikon oluşmuyor.
- [ ] Kapanışta ikon temizleniyor; HICON/GDI kaynak sızıntısı yok.
- [ ] Aktif ikon yalnız gerçek işlem sonucu onaylandığında görünüyor.
- [ ] Belirsiz, uygulanıyor, geri alınıyor ve hata metinleri gerçeği yansıtıyor.
- [ ] Tooltip, klavye aktivasyonu ve sağ tık menüsü erişilebilir.
- [ ] Performans eylemi mevcut Evet/Hayır onayına bağlı; ikon tıklaması ayar uygulamıyor.
- [ ] Hareket azaltma tercihine uyuluyor; boşta animasyon veya tray timer'ı yok.
- [ ] Benchmark / oyun testi sırasında süs animasyonları çalışmıyor.
- [ ] Yalnız gereken görseller EXE'ye gömülü; harici asset/font/ağ bağımlılığı yok.
- [ ] EXE temiz klasörde de tüm marka varlıklarını gösterebiliyor.
- [ ] Referans panosu, katalog ve belgeler son kullanıcı EXE'sine eklenmemiş.
- [ ] Marka değişimi journal, IPC, GUID/AUMID veya kurtarma yollarını bozmadı.
- [ ] Günlük/state kaydı yalnız yapılan entegrasyonu tamamlanmış gösteriyor.
- [ ] Derleme ve yapılan/atlanmış Windows kontrolleri kullanıcıya raporlanmış.

Donanım optimizasyonu veya FPS etkisi bu kabul listesinin kapsamı değildir.
