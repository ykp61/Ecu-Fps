# Proje özeti

Kullanıcı Ecu Fps; ürün adı Ecu Fps (dağıtım dosyası EcuFps.exe). Hedef oyun performansını desteklenen ayarlarla iyileştirmek, darboğazı ölçerek açıklamak ve tüm kendi değişikliklerini geri alabilmektir. İlk hedef Windows 11 x64, Intel/AMD CPU ve NVIDIA/AMD/Intel GPU. Windows 10 uyumluluğu ayrı doğrulama satırıdır; ARM64/32 bit için aynı binary ve kontrol kapsamı varsayılmaz.

Ürün tavsiye listesini Windows menülerinde kullanıcıya uygulatmaz. Desteklenen ayarı onayla kendisi uygular. Fiziksel kapasite, destek dışı firmware veya ölçülemeyen kök neden için açık sınır bildirir.

Kullanıcının son kararları: önce tüm modüllerin v1 kapsamına alınması; sonra Claude Code veya Codex için yeniden uzun prompt gerektirmeyen klasör; uygulama koduna bu devir hazırlığı sırasında başlanmaması. Yeni görsel istenmedi; büyük butonlar küçülecek.

Geliştirme ve ürün modu farklıdır. Aşamalar/dallar ekip iş düzenidir; kullanıcıya sessiz, dengeli veya rekabetçi seçimi çıkarmaz. İlk deneme EXE'si alpha olabilir; v1.0 iddiası kabul matrisinden sonra yapılır.

Başarı garantisi tüm bilgisayarlarda yüksek FPS değildir. Ölçülebilir iyileşme, düşük araç yükü, doğru teşhis, bozulma halinde geri dönüş ve dürüst destek kapsamıdır.
